# RepoMind

An LLM-powered codebase analysis and semantic search system.

## Goal

RepoMind analyzes software repositories and allows users to search and ask questions about their codebase using traditional search, semantic retrieval, and large language models.

## Planned Features

- Repository scanning
- Python AST analysis
- Code indexing
- Keyword search
- Semantic search
- LLM-powered question answering
- REST API
- Docker deployment
- Automated testing
